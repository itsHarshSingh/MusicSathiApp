# 🎵 Music Sathi - Android Music Player App

An intuitive and lightweight offline music player Android application built natively using Java and the Android MediaPlayer API. Designed to provide a smooth, lag-free local audio playback experience with a clean, minimal user interface.

## ✨ Key Features

* **Local Audio Integration:** Seamlessly scans and fetches audio files directly from device storage.
* **Full Playback Controls:** Supports Play, Pause, Next, and Previous track navigation.
* **Optimized Performance:** Engineered for smooth, lag-free performance with minimal resource consumption.
* **Modern Minimal UI:** Clean layout designed for an enhanced and distraction-free user experience.

## 🛠️ Tech Stack & Architecture

* **Language:** Java (Native Android Development)
* **Core API:** Android `MediaPlayer` API for audio management and playback control
* **Storage Access:** Storage Permissions for local media retrieval
* **IDE:** Android Studio
