Music Sathi is a Android music player app built using Java. It fetches audio files from device storage and supports play, pause, next, and previous controls.

🚀 Features
▶️ Play / Pause music playback
⏭️ Next / Previous track navigation
🎵 Built using Android MediaPlayer API
📱 Clean and minimal UI design
⚡ Smooth and lag-free performance
📂 Local audio file support
